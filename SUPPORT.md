# Support

NEXUS is a pre-release desktop application. Before requesting help, include the NEXUS version, Windows/macOS version, architecture, exact command or UI action, and a redacted error message. Do not attach databases, logs containing usernames or paths, credentials, or private performance data.

For build problems, start with `docs/BUILD_FROM_SOURCE.md`. For installation problems, see `docs/WINDOWS_INSTALLATION.md` or `docs/MACOS_INSTALLATION.md`. Security issues belong in the private process described by `SECURITY.md`, not a public support request.
